Arrify discovery release-date correction — 2026-11-27

Problem and behavior
The running helper repeatedly fails at score(): int('') raises ValueError.
Read-only inspection found ten cached resolved records with blank release dates.
A release date must be a real calendar-valid YYYY, YYYY-MM or YYYY-MM-DD string.
Missing, null, whitespace, malformed and non-string values receive no recency
bonus. Dates in future years receive no recency bonus. Evidence scores remain
unchanged. No date or release year is written, guessed, or substituted.

Discovery now defers a cached resolved recording with an invalid first-release
date to the unresolved report with a metadata-review reason. It continues other
songs. This also prevents the later per-year acquisition counters from failing.
Malformed chart hints cannot fail candidate ordering. Chart-year fallback is
used only to schedule metadata resolution; it is never stored as release metadata.
Existing requests, transfers and cached source metadata are not rewritten.
