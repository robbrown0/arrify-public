# Arrify 0.3.0 (40) — beta testing

- Stay signed in with one-hour access tokens and a 30-day inactivity period that
  renews during foreground use, without a fixed absolute login cutoff.
- Temporary connection failures preserve your login. Interrupted token refreshes
  can recover across retries and app restarts.
- Expired or revoked sessions open Sign in automatically; signing in restores
  current playback information and controls.
- Authentication diagnostics now distinguish network deferrals from sign-in needs.

Please test Wi-Fi/cellular changes, VPN interruptions, offline relaunch, and signing
back in while another device is playing. Existing fast cached song transitions are
preserved. This build does not change cache capacity or download selection.

A refresh interrupted for more than 24 hours may still require signing in again.
Existing external beta clients remain supported but need this app update for the
new recovery behavior. Available to internal and external beta testers after TestFlight processing and any required beta review. No App Store release.
