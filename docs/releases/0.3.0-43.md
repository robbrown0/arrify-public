# Arrify 0.3.0 (43) — browsing and bookshelf recovery

- Songs, Albums, Artists, and Audiobooks retry brief connectivity and server failures automatically before offering retry controls.
- Keep the last successful bookshelf visible during an outage; show an empty shelf only after a successful empty response.
- Reconnect visible library screens automatically when connectivity returns, while preserving loaded rows and pagination.
- Separate artwork downloads from interactive requests so slow or unavailable covers cannot hold up browsing.
- Bound artwork work per media source, and preserve the saved catalog when a source scan is interrupted.
- Improve privacy-safe diagnostics for connectivity, server responses, identity checks, and authentication failures.

Please test browsing and returning to Audiobooks after changing networks or briefly
going offline. Confirm known books remain visible, recovery needs no force quit,
and music's fast cached transitions continue to work.
