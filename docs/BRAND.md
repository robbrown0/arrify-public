# Arrify identity

Aurora is Arrify's original emerald-to-aqua folded-A icon, selected by the owner from an AI-assisted concept exploration. The iOS asset is an opaque 1024-pixel square; platform masks supply rounded corners. Web exports use the same source artwork.

Administrators can upload or reset the server icon in Admin → Branding. Browser uploads are converted to PNG, validated and normalized again on the server, and stored separately under the private data directory. Custom branding appears on web sign-in/navigation and inside the signed-in native app. Native Home Screen icons are bundled assets and require an app release; server uploads cannot change them.

Keep third-party service marks and commercial album artwork separate from Arrify's identity. Do not overwrite an administrator's custom icon during an upgrade.
